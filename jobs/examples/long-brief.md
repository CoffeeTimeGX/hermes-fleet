# Weekly episode

(This file is the whole prompt for the `long-brief.json` job. `fleet dispatch` reads it
because the job names it in `prompt_file`. Use this form when the instructions are long
or when you want to keep them under version control next to the job.)

Make this week's long-form episode for Example Channel.

1. Topic: how the James Webb Space Telescope sees in infrared, for a general audience.
2. Write the script to `./output/script.md`, about 1,200 words, with chapter headings.
3. Produce `./output/video.mp4` (1920x1080, 8 to 10 minutes), `./output/thumbnail.png`
   (1280x720) and `./output/metadata.json` (title, description, tags, chapters with
   start times).
4. Nobody can answer questions during the run: make reasonable choices and list them in
   your final summary.
